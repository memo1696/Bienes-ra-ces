## 1. Arquitectura General y Módulos del Sistema

El sistema está diseñado con una arquitectura modular orientada a la seguridad, control operativo y una experiencia de usuario fluida para equipos comerciales de bienes raíces.

### 1.1 Módulos Principales
1. **Gestión de Propiedades (Catálogo Global):** Control de inmuebles activos, en proceso y disponibles.
2. **Historial de Propiedades (Cierre y Trazabilidad):** Registro inalterable de propiedades vendidas con datos completos del comprador, fecha y monto de cierre.
3. **Control de Ingresos y Finanzas:** Registro automático de comisiones, pagos iniciales, reservas y alquileres.
4. **Directorio de Clientes:** Base de datos unificada de compradores, propietarios e inversionistas.
5. **Generador de Enlaces de WhatsApp:** Creación automática de catálogos personalizados para clientes con un mensaje profesional de atención al cliente preformateado.
6. **Control de Accesos (Roles):** Múltiples usuarios con perfiles diferenciados (Administrador, Agente Comercial, Finanzas).

## 2. Esquema de Base de Datos (SQL / Relacional)

```sql
-- Tabla de Usuarios del Sistema (Equipo Interno)
CREATE TABLE usuarios (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    rol ENUM('Administrador', 'Agente', 'Finanzas') DEFAULT 'Agente',
    estado BOOLEAN DEFAULT TRUE,
    creado_en TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Tabla de Clientes (Compradores y Propietarios)
CREATE TABLE clientes (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(150) NOT NULL,
    telefono VARCHAR(20) NOT NULL,
    email VARCHAR(100),
    tipo ENUM('Comprador', 'Propietario', 'Inversionista') DEFAULT 'Comprador',
    notas TEXT,
    creado_en TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Tabla de Propiedades
CREATE TABLE propiedades (
    id INT AUTO_INCREMENT PRIMARY KEY,
    codigo VARCHAR(50) UNIQUE NOT NULL,
    titulo VARCHAR(150) NOT NULL,
    tipo_inmueble VARCHAR(50) NOT NULL, -- Casa, Apartamento, Terreno, Local
    operacion ENUM('Venta', 'Alquiler') DEFAULT 'Venta',
    precio DECIMAL(12,2) NOT NULL,
    ubicacion VARCHAR(255) NOT NULL,
    habitaciones INT DEFAULT 0,
    banos INT DEFAULT 0,
    area_m2 DECIMAL(10,2),
    estado ENUM('Disponible', 'Reservada', 'Vendida') DEFAULT 'Disponible',
    descripcion TEXT,
    imagen_url VARCHAR(500),
    creado_en TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Tabla de Historial y Transacciones (Propiedades Vendidas)
CREATE TABLE historial_propiedades (
    id INT AUTO_INCREMENT PRIMARY KEY,
    propiedad_id INT NOT NULL,
    cliente_id INT NOT NULL,
    usuario_id INT NOT NULL,
    precio_venta DECIMAL(12,2) NOT NULL,
    fecha_venta DATE NOT NULL,
    detalles_cierre TEXT,
    FOREIGN KEY (propiedad_id) REFERENCES propiedades(id),
    FOREIGN KEY (cliente_id) REFERENCES clientes(id),
    FOREIGN KEY (usuario_id) REFERENCES usuarios(id)
);

-- Tabla de Control de Ingresos
CREATE TABLE ingresos (
    id INT AUTO_INCREMENT PRIMARY KEY,
    propiedad_id INT,
    cliente_id INT,
    usuario_id INT,
    monto DECIMAL(12,2) NOT NULL,
    concepto VARCHAR(150) NOT NULL, -- Comisión de Venta, Reserva, Alquiler
    fecha_pago DATE NOT NULL,
    metodo_pago VARCHAR(50), -- Transferencia, Efectivo, Tarjeta
    FOREIGN KEY (propiedad_id) REFERENCES propiedades(id),
    FOREIGN KEY (cliente_id) REFERENCES clientes(id),
    FOREIGN KEY (usuario_id) REFERENCES usuarios(id)
);
